# kid-mapping

This is repository contains the code to do line scanning of MKID arrays using an Android phone.

- This project requires python=>3.9 and python=<3.12
- Activate a virtual environment
- Open a terminal
- run: pip install -r requirements.txt 
- All dependencies should be installed
- run 'scrcpy-win64-v211/adb.exe' to install ADB if on a Winwdows 64-bit system. If another system is used appropriate versions can be installed here: https://scrcpy.org/download/
